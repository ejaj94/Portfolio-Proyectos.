# 🛡️ Sentinel Node PRO - Dashboard Cyberpunk de Recursos

Plataforma de telemetria e monitorização de processos e recursos do sistema em tempo real, desenvolvida em **Python**, **Flask**, **psutil** e **Chart.js** com um design estético **Cyberpunk / Sci-Fi Neón**.

---

## ✨ Características Principais

- ⚡ **Telemetria em Tempo Real (2s Refresh)**: Monitorização contínua de utilização de CPU (%), memória RAM (GB/%), disco principal (C:) e tráfego de E/S de rede.
- 🎨 **Design Cyberpunk Neón Brutal**: Estética em tons preto obsidiana, cian néon, magenta néon, verde cyber e roxo elétrico com tipografia `Orbitron` e `Share Tech Mono`.
- 📊 **Gráficos de Tendência (Chart.js)**: Visualização dinâmica da carga de CPU e RAM ao longo do tempo.
- 📋 **Gestão e Inspeção de Processos**: Tabela interativa com pesquisa em tempo real, ordenação por consumo de recursos e modal de inspeção detalhada por PID.
- 📺 **Consola de Telemetria**: Feed de registos e eventos do sistema com marcação temporal.

---

## 🛠️ Instalação e Utilização

1. Instalar dependências:
   ```bash
   pip install -r requeriments
   ```
2. Executar a aplicação web:
   ```bash
   python app.py
   ```
3. Abrir no navegador:
   ```text
   http://localhost:5007
   ```
