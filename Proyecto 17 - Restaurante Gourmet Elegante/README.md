## 🛠️ Instalação e Execução

1. Instalar dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Executar o servidor Flask:
   ```bash
   python app.py
   ```
3. Abrir no navegador (Smartphone ou PC):
   ```text
   http://localhost:5023
   ```
