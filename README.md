## 📖 Sobre o Portfólio

Este repositório reúne a totalidade do código-fonte construído ao longo da jornada histórica dos **100 Dias e 100 Projetos de Programação**. O objetivo foi provar, na prática e sem atalhos, a capacidade de arquitetar, programar, testar e publicar uma aplicação funcional por dia, cobrindo as mais diversas indústrias e padrões modernos de engenharia de software.

O resultado é um ecossistema com **mais de 100 aplicações completas**, variando de micro-serviços a suites empresariais *All-in-One*, APIs RESTful, motores de scraping, dashboards telemétricos e interfaces com design *Cyber-Glassmorphism Ultra 8K*.

## 🚀 Como Executar Localmente

### 1. Clonar o Repositório
```bash
git clone https://github.com/ejaj94/Portfolio-Proyectos..git
cd "Portfolio-Proyectos."
```

### 2. Criar e Ativar o Ambiente Virtual
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Instalar as Dependências Globais
```bash
pip install -r requirements.txt
```

### 4. Executar Qualquer Projeto
Cada pasta é um micro-serviço autónomo pronto a rodar:
```bash
# Exemplo 1: Executar o Projeto 116 (NEXUS Business OS)
cd "Proyecto 116 - Business OS"
python app.py
# Aceder em http://localhost:6969

# Exemplo 2: Executar o Projeto 117 (Showcase dos 100 Dias)
cd "../Proyecto 117 - Showcase 100 Dias"
python app.py
# Aceder em http://localhost:6970
```

## 🌟 Princípios de Engenharia Adotados

1. **Zero Bloat & Autonomia Total**: Cada projeto funciona de forma independente com a sua própria base de dados SQLite e assets, sem dependência de serviços externos pagos para execução local.
2. **Experiência do Utilizador (UI/UX)**: Aplicação consistente de design system moderno, feedback visual em cada ação, modais responsivos e transições fluídas.
3. **Código Limpo & Legível**: Separação clara entre camada de rotas (`app.py`), persistência de dados (`database.py`) e visualização (`templates/` e `static/`).
