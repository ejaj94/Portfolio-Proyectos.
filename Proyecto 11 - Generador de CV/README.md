# 📄 CV Studio Builder PRO - Criador de Currículos Executivos (Smartphone & PC)

Aplicação Web trilingue (Português de Portugal, Español, English) responsiva para a criação, visualização em tempo real e exportação em PDF de Currículos Profissionais Executivos.

---

## ✨ Características Principais

- 📱 **Multi-Dispositivo (Smartphone & PC)**: Interface totalmente responsiva que se adapta a ecrãs tácteis de telemóveis e monitores de computador.
- 🎨 **Design Claro Light SaaS Corporativo**: Estética moderna em tons de porcelana suave, vidro deslustrado e acentos em Índigo Executivo, Esmeralda e Cian.
- 👁️ **Vista Prévia em Tempo Real**: Atualização instantânea do documento à medida que os dados são introduzidos.
- 🖼️ **Carga de Foto com Máscara Circular**: Suporte para fotografia de perfil recortada automaticamente em formato circular.
- 📑 **Estilos de Documento**: Seleção entre 3 temas visuais (*Índigo Executivo*, *Nórdico Mínimo*, *Verde Esmeralda*).
- 📥 **Exportação PDF de Alta Qualidade**: Compilação de PDF executivo através do motor **ReportLab** em Python.

---

## 🛠️ Instalação e Utilização

1. Instalar dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Executar a aplicação:
   ```bash
   python app.py
   ```
3. Abrir no navegador (Smartphone ou PC):
   ```text
   http://localhost:5008
   ```
